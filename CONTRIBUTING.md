## Current Contribution Policy

This project is open source under the MIT License and is publicly available for use, modification, distribution, and forking in accordance with that license.

The upstream repository is currently maintained under a closed contribution model. Only authorized maintainers from ANG Schweiz AG may merge changes into the official repository.

External code contributions and unsolicited pull requests are not currently accepted. External users are welcome to:

- report reproducible bugs;
- request features;
- suggest documentation improvements;
- describe relevant SAP Business One integration use cases; and
- report security vulnerabilities privately according to `SECURITY.md`.

Issues and feature requests are reviewed and prioritized by the maintainers. Submission does not guarantee implementation, support, inclusion in the roadmap, or a specific response time.

This contribution model may change in the future. ANG Schweiz AG may open the project to external code contributions and pull requests once the project structure, development standards, review process, and long-term maintenance model are sufficiently established. Any change to the contribution policy will be documented in this file.

Users remain free to fork and modify the project under the terms of the MIT License.
